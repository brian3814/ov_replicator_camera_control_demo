  5. Widget Ownership & Data Flow

  ┌──────────────────────────────────────────────────────────────────────────┐
  │                        DATA OWNERSHIP DIAGRAM                            │
  └──────────────────────────────────────────────────────────────────────────┘

                      ┌─────────────────────┐
                      │     Window          │
                      │  (owns all state)   │
                      └─────────────────────┘
                                │
            ┌───────────────────┼───────────────────┐
            │                   │                   │
            ▼                   ▼                   ▼
   ┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
   │ GlobalSettings  │ │ CameraSettings[]│ │ Controllers     │
   │ - output_folder │ │ - prim_path     │ │ - Capture       │
   │ - status        │ │ - width/height  │ │ - Preview       │
   └─────────────────┘ │ - fps, fov...   │ └─────────────────┘
                       └─────────────────┘
                                │
                                │ passed by reference
                                ▼
                       ┌─────────────────┐
                       │CameraPanelWidget│
                       │ _settings (ref) │◄── Same object, updates in-place
                       └─────────────────┘
                                │
                ┌───────────────┼───────────────┐
                │               │               │
                ▼               ▼               ▼
       ┌─────────────┐  ┌─────────────┐  ┌─────────────┐
       │Resolution   │  │Resolution   │  │CameraProperty│
       │Widget       │  │Widget       │  │Widget (x4)  │
       │(Width)      │  │(Height)     │  │             │
       │_value: int  │  │_value: int  │  │_value: float│
       └─────────────┘  └─────────────┘  └─────────────┘
             │               │               │
             └───────────────┴───────────────┘
                             │
                      Callbacks bubble up
                             │
                             ▼
                      ┌─────────────────┐
                      │ Window          │
                      │ _save_state()   │
                      └─────────────────┘
                             │
                             ▼
                      ┌─────────────────┐
                      │ camera_state.json│
                      └─────────────────┘
